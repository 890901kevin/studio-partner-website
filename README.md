# STUDIO A 夥伴工作入口

此專案使用 HTML、CSS 與 JavaScript，不需要安裝套件。

- `index.html`：頁面內容與 iPhone 捷徑連結
- `style.css`：STUDIO A 藍色主題與手機排版
- `app.js`：六個系統連結、分類與搜尋
- `assets/`：品牌標誌與圖示

使用 VS Code 開啟本資料夾即可編輯。雙擊 index.html 可直接用瀏覽器查看。儲存後重新整理瀏覽器即可看到變更。

如需本機網站預覽，可在 VS Code 終端機輸入 `python3 -m http.server 5500`，再開啟 http://localhost:5500。

本機修改不會自動同步到線上網站，完成後需另外重新發布。各系統仍使用原本的登入方式。
